# ABSENDSI Web

Aplikasi Absensi Web untuk **Geprekin** — UI modern clean ala **KAI Access**.

## Fitur
- ✅ Masuk & Keluar (Check-In / Check-Out)
- ✅ Koreksi Absensi
- ✅ Tukar Shift
- ✅ Data Pekerja
- ✅ Pengajuan Lembur
- ✅ Slip Gaji

## Tech
- Next.js 15 (App Router)
- Tailwind CSS
- localStorage (simulasi data lokal)
- Mobile-first, PWA-ready

## Development
```bash
npm install
npm run dev
```

## Deploy
Push ke repo `astiakanlol/absendsi-web` lalu connect ke Vercel.

Dibuat dengan standar QIORI — zero silent failure, cascade, anti-bug.
